# Homebrew Tap for Max Watch

Official Homebrew Cask tap for [**Max Watch**](https://github.com/MaxFreedomPollard/Max-Watch), a 100% offline, free, encrypted Mac video recorder with motion detection (`macOS 13.0+`, Apple Silicon & Intel).

## Install

```bash
brew tap maxfreedompollard/tap
brew install --cask max-watch
```
